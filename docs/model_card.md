# Model card

## Comprehension provider (live)

- **Adapter:** `AnthropicProvider` with Messages API forced tool use against the `Candidate` JSON schema.
  Model id defaults to `claude-sonnet-5-5`, overridable with `HUMOUR_ENGINE_MODEL`.
- **Status:** built and tested offline with an injected transport. **Not exercised against the real API**,
  because no key is present in this environment. Comprehension quality is unmeasured.
- **Controls:** off unless the request allowlists `anthropic` and sets `allow_external_inference`. Every call
  (initial, repair, critic) reserves budget first. Pricing is unknown in the repo, so a strict dollar cap stops
  before charging.
- **Prompt:** `analysis/prompt.py`, version `comprehension-v1`. Baselines `plain` and `ontology` exist for ablation.

## Style classifier (local_model)

- **What it predicts:** one of five MaryKenneth humour-style labels. This is a source-specific
  social-function prediction. It is not comprehension and says nothing about the speaker.
- **Architecture:** TF-IDF features (word 1-2 grams and char_wb 2-5 grams) with logistic regression. Two
  variants: single five-class, and hierarchical (four-class gate plus an affiliative/aggressive specialist,
  composed softly so the full five-class distribution is always computed). Temperature calibration is fitted
  on the calibration partition.
- **Deployed:** the `single` variant, C=8, chosen on dev macro-F1. The artifact `artifacts/style_model.pkl`
  is regenerated by `humour evaluate style` and loads only if its sha256 matches its sidecar.
- **Measured (sealed test, 202 texts, evaluated once):** macro-F1 0.602 single, 0.615 hierarchical, 0.076
  majority. Hierarchical minus single: +0.013, 95% CI [-0.015, 0.043], so **no demonstrated improvement**.
  Weakest classes: affiliative (F1 0.43) and self-deprecating (F1 0.48). Full report:
  `evals/reports/style-mk5-v1.md`.
- **Not a reproduction** of the upstream papers. The features differ (no GTE or DistilBERT) and the split is
  the engine's own family-grouped split.
- **Known failure observed:** it labels "I made a detailed plan to become more spontaneous." as neutral. It
  carries no mechanism knowledge.

## Attribution

LIME-style word removal over `StyleModel.predict_proba`, the same path used for inference, including the
hierarchical composition and temperature. It records seed, samples, kernel width, weighted-R² fidelity and
top-k stability across three seeds. It is only available for this local model. Closed models return
`unsupported`.
