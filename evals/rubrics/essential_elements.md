# Essential-element rubric

For each item, at least one human-endorsed interpretation lists its essential elements before any system output
is seen. An explanation is scored on:

| # | Element | Score |
|---|---|---|
| 1 | Identifies the relevant reading or ambiguity | 0/1 |
| 2 | Explains the connection between the setup/context and the trigger | 0/1 |
| 3 | Cites evidence that actually supports that connection | 0/1 |
| 4 | Makes no unsupported context, intent, delivery or personality claim | 0/1 (any unsupported claim = 0) |
| 5 | Acknowledges necessary missing information | 0/1 (n/a when nothing is missing) |

Report coverage of essential elements, the unsupported-claim rate and the contradiction rate per system.
A supported alternative reading that a human endorses scores as correct even if it differs from the first
reference. A correct label with a fabricated explanation fails element 3 or 4.
